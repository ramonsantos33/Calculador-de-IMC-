# Calculadora de IMC 🧮

Este é um projeto simples de uma Calculadora de Índice de Massa Corporal (IMC) que desenvolvi para colocar meus conhecimentos em prática.

## 🚀 Tecnologias Utilizadas
HTML, CSS e JavaScript 

## 💡 Como funciona
O programa recebe o peso e a altura do usuário, realiza o cálculo padrão de IMC e retorna em qual categoria a pessoa se encontra (Abaixo do peso, Peso normal, Sobrepeso, etc.).

## 🛠️ Como rodar o projeto

Como este é um projeto web estático, não é necessário instalar nenhuma dependência ou ambiente virtual para testá-lo.

1. Faça o download deste repositório em formato ZIP ou faça o clone via Git.
2. Extraia a pasta na sua máquina.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador de preferência .
